# Actividad 3.3 · Implementación serverless · VcM

Caso: **Sistema de Monitoreo Remoto de Pacientes Críticos**.
EA3 · IL4.3 · 7 horas pedagógicas según PA.
Leer el [enunciado común](../../Enunciado_VcM_ARY1102.md).

## Trabajo

1. Implementa funciones, API y almacenamiento. Reutiliza/adapta `app/domain.py`;
   desarrolla los adaptadores cloud según tus decisiones.
2. Implementa desacoplamiento, duplicados y mensajes fallidos; prueba repetición,
   datos inválidos y recuperación después de fallo provocado.
3. Demuestra el recorrido de un evento crítico hasta un canal de alerta de prueba
   y su registro; no enviar a personas reales.
4. Completa autorización de dos roles, cambios versionados de reglas, historial
   de acciones/acuse ficticio, auditoría y exportación.
5. Mide latencia/errores, observabilidad, recuperación y costos. Compara EA2 y
   objetivos productivos, sin afirmar cumplimiento no medido.
6. Integra interfaz/consulta contenerizada para la EFT y la exposición VcM.

## Entrega y revisión formativa

Código, diagrama, configuración, pruebas reproducibles, limitaciones y RF/RNF.
EP3 conserva informe y defensa individuales con instrumento institucional.
El **Hito 3** expone resultados y cambios derivados del feedback. Fecha y
modalidad pendientes de confirmación.
