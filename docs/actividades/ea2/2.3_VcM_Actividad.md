# Actividad 2.3 · Implementación con orquestación y PaaS · VcM

Caso: **Sistema de Monitoreo Remoto de Pacientes Críticos**.
EA2 · IL3.3 · 7 horas pedagógicas según PA.
Leer el [enunciado común](../../Enunciado_VcM_ARY1102.md).

## Trabajo

1. Implementa datos administrados compartidos y adapta la capa de almacenamiento;
   conserva el contrato. Una SQLite independiente por tarea no acredita HA.
2. Construye/publica imágenes antes de desplegar; documenta versión y arquitectura.
   Las tareas descargan imágenes publicadas mediante sus permisos de ejecución.
3. Despliega en orquestador cloud con ingreso, salud, red, secretos y observabilidad.
   Explica el servicio administrado seleccionado.
4. Demuestra estados, historial, alertas y ventana temporal. Prueba datos inválidos,
   IDs repetidos y conflictos de contenido.
5. Reinicia una réplica y demuestra persistencia compartida. Prueba carga acotada,
   latencia, errores y escalamiento real; min/max no prueba escalamiento automático.
6. Conserva evidencias, comandos reproducibles, costos y procedimiento de limpieza.

## Entrega y revisión formativa

Código/adaptadores e infraestructura, diagrama final, orquestador y servicio
administrado, resultados de red/función/fallo y matriz RF/RNF.
EP2 conserva encargo y defensa individuales con instrumento institucional.
El **Hito 2** admite avance parcial: reportar pruebas pendientes y no esperar
a completar toda esta actividad para enviar durante la semana indicada.
